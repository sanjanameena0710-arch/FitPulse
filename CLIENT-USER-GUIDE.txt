SHURUAT (Getting Started)
================================================================

INSTALL KARNA:

   📱 MOBILE APP (Android):
      1. FitPulse.apk file download karein
      2. Phone settings → Security → "Unknown sources" allow karein
      3. APK file pe tap karein → Install
      4. App khol ke account banayein

   🌐 WEBSITE:
      1. Apne browser mein URL kholen (jo humne diya hai)
      2. Phone screen pe "Add to Home Screen" karein
         (icon banega — app jaisa)
      3. Khol ke account banayein

FIRST TIME LOGIN:

   Option 1 — Demo Account try karein:
      Email: demo@fitpulse.app
      Password: demo123
      (Sample data already hai — explore kar lo)

   Option 2 — Apna account banayein:
      "Sign up" tap karein → Naam, Email, Password
      Password: minimum 6 letters

▼ PROGRESS PHOTOS (Before/After)
─────────────────────────
Apni transformation dekhne ke liye:

   1. Profile → Progress Photos
   2. + button (camera icon) tap karein
   3. Phone se photo le ya gallery se choose karein
   4. Weight aur note add karein → Save
   5. SIDE-BY-SIDE COMPARE:
      - Compare button tap karein
      - 2 photos select karein
      - Auto compare ho jaaegi
      - Weight change bhi dikhega!

   ⚠ PRIVACY: Photos sirf aapke device pe save hain.
            Server par nahi jaate.

▼ DATA BACKUP
─────────────────────────
Apna data safe rakhne ke liye:

   1. Profile → Export Data
   2. JSON file download hogi
   3. Email/Drive pe save karein
   4. Phone change ho ya app uninstall ho:
      - Naya install karein
      - Profile → Import Data
      - JSON file select karein
      - Saara data wapas!

COMMON PROBLEMS (FAQ)
================================================================

Q: App khulta nahi
A: Phone restart karo. Phir bhi nahi to reinstall.

Q: Camera ne reps count nahi kiye  
A: + button se manually add kar lo
   Light kam ho to brighter jagah pe karo
   Camera flip kar ke try karo

Q: Login nahi ho raha
A: Email aur password check karo
   "Use demo" button try karo

Q: Data delete ho gaya
A: Browser cache clear ho gaya hoga
   Backup hai to import karo
   Future mein weekly export karo

Q: APK install nahi ho raha
A: Settings → Security → Unknown sources allow karo
   Old version uninstall karo phir try karo

Q: Camera permission denied
A: Phone settings → Apps → FitPulse → Permissions
   → Camera "Allow" karo
   App reopen karo

Q: Internet ki zaroorat hai?
A: NAHI! Sab kuch offline kaam karta hai.

Q: Multiple users use kar sakte hain?
A: Ek device pe ek hi user. Logout-Login se switch.

Q: Web version aur mobile data sync hota hai?
A: Nahi, dono separate hain. Manual export/import karen.
