6) APK KAISE BANAYEN (Mobile App)
================================================================

Aap ke paas FitPulse-APK-Build.zip hai. Iske 2 tareeke hain:

OPTION A — EAS Build (RECOMMENDED, free):
   1. https://expo.dev par account banao
   2. Terminal mein: npm install -g eas-cli
   3. cd FitPulse-APK-Build
   4. npm install
   5. eas login
   6. eas build --platform android --profile preview
   7. ~15 min mein APK link mil jaayega — download karo

OPTION B — Local build:
   1. Android Studio install
   2. cd FitPulse-APK-Build
   3. npx expo prebuild
   4. cd android && ./gradlew assembleRelease
   5. APK milega: android/app/build/outputs/apk/release/

CLIENT BRANDING change karne ke liye:
   - app.json file edit karo
   - "name": "Aap Ka App Naam"
   - "ios.bundleIdentifier" aur "android.package": "com.clientname.app"
   - assets/images/icon.png replace karo
